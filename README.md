# SketchLite — лёгкий аналог ibisPaint X на Flutter

Мобильное приложение для рисования (Android / iOS): галерея работ, холст с жестами,
кисти, цвет (палитра / RGB / HSB), неограниченные слои с режимами наложения.
Рабочее название — SketchLite (логотип можно заменить в `ui/home/home_screen.dart`).

> **Статус.** Код написан по вашему ТЗ и скриншотам ibisPaint X, но **в окружении, где он создавался,
> не было Flutter SDK и сети — проект ни разу не компилировался и тесты не запускались.**
> Первый шаг у вас: `flutter pub get && flutter analyze && flutter test`. Если анализатор что-то найдёт —
> это будут мелкие правки, структура от них не зависит.

## Запуск

Папок `android/` и `ios/` в архиве нет — их создаёт Flutter:

```bash
cd sketchlite
flutter create . --platforms=android,ios --project-name sketchlite
flutter pub get
flutter analyze
flutter test
flutter run
```

Разрешения для импорта фото (`image_picker`):
* iOS — в `ios/Runner/Info.plist` добавьте `NSPhotoLibraryUsageDescription` (и `NSCameraUsageDescription`, если подключите камеру).
* Android — на современных версиях ничего не нужно (используется системный Photo Picker).

Требования: Flutter ≥ 3.27, Dart ≥ 3.6.

## Как устроено рисование

1. **Штрих** (`StrokeOp`) хранит точки (с нажимом), кисть, цвет, размер, непрозрачность и режим.
   Он рисуется в отдельном `saveLayer`, а потом накладывается на слой целиком с общей непрозрачностью —
   поэтому перекрывающиеся штампы не «копят» прозрачность.
   * кисть → `srcOver`; **ластик** → `dstOut`; **блокировка альфа-канала** → `srcATop`;
   * активное **выделение** (лассо/прямоугольник) запоминается в штрихе как `clip`.
2. **Слой** (`Layer`) = исходная картинка + список операций. Каждые 8 операций они «запекаются» в
   `ui.Image`-кэш, чтобы кадр не перерисовывал тысячи штрихов. Пустой слой не занимает растровой памяти,
   поэтому число слоёв ничем не ограничено, кроме RAM (≈ `w·h·4` байт на непустой слой).
3. **Компоновка** (`Compositor.paintLayers`): для каждого слоя `saveLayer` с его прозрачностью и режимом
   наложения; слои с флагом «обтравка» рисуются через `srcATop` поверх базового слоя группы.
   Тот же код используется для экрана, экспорта, миниатюр и пипетки.
4. **История**: паттерн Command (`AddOpCommand`, `AddLayerCommand`, `MoveLayerCommand`, `LayerPropsCommand`,
   `ReplaceContentCommand`, …), глубина 200. Слияние и отражение слоя — тоже команды.
5. **Жесты** (`CanvasView`): один палец/стилус — рисование; второй палец отменяет начатый штрих и включает
   pinch-zoom + поворот + панорамирование (матрица вида в контроллере). Режим «только стилус» и режим «рука»
   переключаются сверху.

## Что нового в 0.2.0

* **Главный экран:** «Недавние работы» (быстро продолжить), рейтинг и Премиум убраны.
* **Вектор:** векторный слой (кнопка в панели слоёв или сам инструмент). Обычная кисть на таком слое
  превращается в вектор; есть перо (касание — угол, протяжка — гладкая точка), фигуры, выбор рамкой/лассо,
  правка вершин (гладкий/нормальный/угловой), упрощение, стиль (цвет, толщина, заливка, пунктир, концы),
  порядок форм, отражение, дублирование, объединение/вычитание/пересечение, векторный ластик.
* **Лассо:** лассо, многоугольник, прямоугольник, эллипс; добавить/вычесть; инвертировать, залить, очистить,
  копировать/вырезать в слой.
* **Спецкисти (8):** перо пластичности (5 типов + толщина), заливка лассо, ластик лассо, копирующая кисть
  (относительная / неподвижная / подвижная), кисть параллельной и концентрической градации.
* **Фильтры, Палец.**
* **Преобразовать:** преобразование, перспектива, сетка + **Puppet Warp** (авто-сетка с плотностью,
  ручная сетка вершин/рёбер, булавки, «Изменить сетку»).
* **Жесты:** касание двумя пальцами — отмена, тремя — возврат.
* **ColorDrop:** зажмите квадратик цвета внизу, вытащите на холст или на слой в панели слоёв — зальётся
  (на векторном слое заливается фигура).

* **Волшебная палочка, Размытие, Текст, Разделитель фреймов.**
* **Зеркало** (кнопка-линейка наверху или пункт в меню инструментов): линейки — прямая, круг, эллипс, лучи,
  перспектива; симметрия — зеркало, две оси, вращение (N сегментов), калейдоскоп. Работает со всеми кистями,
  ластиком и векторной кистью. Направляющие двигаются цветными точками.
* Нажатие на число рядом с ползунком открывает клавиатуру для ввода значения.
* Авто-сетка Puppet Warp: «только контур» (ширина пояса) и отрицательный отступ.

### Честные ограничения 0.2.0

* Код написан без возможности скомпилировать и запустить его там, где он создавался: возможны мелкие ошибки сборки.
* Копирующая кисть и фильтры работают только на растровых слоях (есть кнопка «Растрировать слой»).
* «Заострённые» концы векторного ластика сделаны как плоский срез.
* Преобразования действуют на весь слой, выделение не учитывают.
* Puppet Warp использует взвешивание по расстоянию, а не ARAP — гнётся мягче и менее «жёстко».

## ROADMAP (не реализовано)

* Текст: нет редактирования надписи после записи в слой (она становится обычными пикселями); нет вставки на векторный слой.
* Анимация (покадровая), таймлапс записи.
* Реальный бэкенд для «Онлайн галереи» и каталога кистей (`OnlineRepository`) и облачная синхронизация
  (синхронизировать папки `<documents>/sketchlite/<id>/`).
* Сохранение пользовательских кистей, палитры и недавних цветов между запусками.
* Выбор и сохранение настроек на экране «Настройки» (сейчас переключатели ничего не меняют).
* Отмена изменений выделения; клиппинг-слой сейчас игнорирует собственный режим наложения.
* Локализация через ARB (строки пока заданы прямо в виджетах, на русском).
* Производительность: заливка и «запекание» работают на полном разрешении; для холстов > 4K стоит
  перейти на тайловое хранение слоёв и ограничить глубину истории по памяти.

## 3.0 — Анимация (этап 1)
Холсты из раздела «Анимация» открываются в режиме анимации (`lib/ui/anim`, данные — `lib/anim`, файл `anim.json` рядом с работой).
- **Таймлайн:** дорожки слоёв и контейнеры «Скелет», глазок, обрезка и сдвиг отрезка, порядок слоёв, ключи (перетаскивание, привязка к кадрам), щипок — масштаб времени.
- **Преобразования слоя/скелета/кости:** перемещение, масштаб, вращение, автоключ, undo/redo.
- **Графики:** кривая параметра, ease-in/out, ступень, кубическая Безье с ручками.
- **Скелет:** иерархия костей (рисуются на холсте), слои привязываются к кости целиком (жёсткий риггинг), кости анимируются.
- **Физика (3.1):** ткань и мягкое тело на сетке слоя (Верле), маска физики кистью (белое — движется, чёрное — неподвижно), коллайдеры (круг/прямоугольник), слои и маски столкновений (8 бит).
- **Сетка и веса (3.1):** автосетка по прозрачности, ручная расстановка вершин, веса костей кистью и «авто-веса», деформация сетки скелетом в реальном времени.
- **Экспорт:** GIF и PNG-секвенция (ZIP). MP4 нет — нужен кодек.
- Из анимации слой открывается в обычном редакторе; сверху переключатель «все слои / только этот / в контексте анимации».

## 3.2
- Таймлайн: колонки названий нет; глазок (слева) и имя слоя (снизу) — полупрозрачные, прямо на слое. Ручки обрезки (белая рамка) — только у выбранного слоя.
- Ключи по типам: перемещение — зелёные, масштаб — синие, вращение — красные, прозрачность — фиолетовые; невыбранные приглушены, ключи выбранного инструмента рисуются сверху.
- Над кнопками перемещения/масштаба/вращения — поле текущего значения; нажатие открывает ввод точных значений.
- Гизмо на холсте: стрелки (перемещение по осям и свободно), оси с квадратами (масштаб по X/Y и общий), кольцо (вращение).

## 3.3 — цепочки костей, мультивыбор ключей, «живые» параметры
- **Кости-цепочки.** Начните тянуть кость у конца любой другой — она приклеится к нему (на стыке кольцо). Кость «на расстоянии»: включите «Связь на расстоянии» и начните на теле кости — она станет дочерней, но останется на месте (пунктир к родителю).
  Карточка выбранной кости: имя, родитель (меняется без прыжков позы), «Приклеить к концу родителя», длина, «Добавить звено», «Цепочка из N звеньев» (для хвостов и волос). Перетаскивание звена цепочки поворачивает его.
- **Несколько ключей.** Кнопка «галочки» в углу таймлайна (или пункт меню ⋮): касание добавляет/убирает колонку ключей, протяжка по пустому месту рисует рамку выделения.
  Выбранные ключи двигаются вместе (тяните за любой из них), дублируются, удаляются, получают одну кривую. Двумя пальцами — зум и прокрутка таймлайна.
- **Параметры (как в Live2D)** — вкладка «Физика» → «Параметры»: ползунок, который одновременно двигает свойства многих объектов (мин/макс), его можно анимировать ключами.
- **Авто-колебания** — вкладка «Физика» → «Колебания»: дыхание, покачивание; для кости — «волна по цепочке» с запаздыванием.

## 3.4
- **Авто-сетка по контуру**: вершины лежат точно на границе рисунка (нет «огромного зазора»). Два режима: «Только контур» и «С заполнением» (контур + соты внутри). «Отступ от контура» теперь −30…+30 px, по умолчанию 1.5.
- **Физика «По изображению»**: плотная сетка строится сама (шаг — «Детализация»), маску рисовать не нужно, сохраняется площадь треугольников, можно закрепить край (верх/низ/лево/право).
- **Мягкие столкновения**: тела с общим слоем/маской продавливают друг друга — точка, зашедшая внутрь чужого тела, выталкивается к его поверхности, а поверхность прогибается навстречу. Исходные перекрытия не учитываются. Отключается переключателем «Мягкие столкновения».
- **Туториал** в главном меню: 9 уроков, мини-примеры (рисование, выделение, сетка, ключи с мультивыбором, кости-цепочки, физика, параметры/колебания).


## 3.5 — сетка, IK, гравитация, любые значения

* **Сетка:** режим «Выбрать» (тап — выбрать/снять точку, рамка по пустому месту, перетаскивание выбранной точки двигает всю группу),
  кнопки «Подразделить» (рёбра между выбранными точками делятся пополам, веса и маска физики усредняются), «Подразделить всё»,
  «Сгладить» (сила и число проходов), «Все / Снять / Инвертировать / Расширить». У контурных и подразделённых сеток
  топология сохраняется (`fixed` в JSON) и не пересобирается Делоне.
* **IK:** на вкладке «Скелет» — «Добавить IK на выбранную кость». Цепочка из N костей (CCD) тянется к красному прицелу;
  прицел двигается пальцем и анимируется ключами (дорожки `ik:<id>`). Есть «Влияние» 0…1.
* **Гравитация:** тело падает на пол и прогибается (shape matching + пол); закреплённые (чёрные) точки удерживают тело.
* **Любые значения:** в окне ввода числа можно ввести больше максимума ползунка; жёсткие границы остались только там, где иначе всё сломается (цвет, прозрачность, размер кисти, число лучей и т. п.).

## 3.5.1 — булавки и кисти масок

* **Булавки** (вкладка «Физика»): закрепляют часть физического тела (маска и «По изображению»). У каждой — радиус влияния и жёсткость (0 мягко … 1 жёстко); влияние плавно спадает к краю круга. Значения вводятся без ограничений.
* **Кисти масок и весов:** режим «Кисть» красит выбранным значением — чёрный, серый разных оттенков или белый (степень влияния), режим «Размытие» усредняет значения с соседями.
